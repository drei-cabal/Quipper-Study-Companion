# Install Quipper Study Helper

Follow these steps after downloading the release ZIP from GitHub.

## Install

1. Download the ZIP file.
2. Right-click the ZIP file and choose Extract All.
3. Remember the extracted folder location.
4. Open Google Chrome.
5. Go to `chrome://extensions`.
6. Turn on Developer mode.
7. Click Load unpacked.
8. Select the extracted extension folder.
9. Open a Quipper quiz page.
10. Click the Study Helper extension and press Read.

## Important

- Do not select the ZIP file in Chrome. Select the extracted folder.
- If the extension was updated, download the new ZIP, extract it, then click Reload on the extension card in `chrome://extensions`.
- The extension works without an API key, login, server, or database.

## Quick Troubleshooting

- If Read does not work, refresh the Quipper page and click Read again.
- If the question is not detected, select the question text first, then click Read.
- If buttons are disabled, click Read first or paste text into Detected text.
